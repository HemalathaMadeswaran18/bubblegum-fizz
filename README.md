# Bubblegum Fizz

A sweet pink look for Claude Code in the desktop and mobile apps. Strawberry-milk pink by day, a glowing berry soda by night, with iridescent soap bubbles drifting slowly up behind the conversation. The bubbles keep to the edges so your text stays clear, and they hold still if your system asks for reduced motion.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install bubblegum-fizz --marketplace HemalathaMadeswaran18/bubblegum-fizz
```

Answer `y` to add the marketplace, then pick a scope (user is the default).

From a shell:

```bash
claude plugin install bubblegum-fizz --marketplace HemalathaMadeswaran18/bubblegum-fizz
```

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `HemalathaMadeswaran18/bubblegum-fizz`, then **Add plugin**.

The theme draws in the desktop and mobile apps; the terminal keeps its own colors.
